# 【一院科普】关爱老年人健康，关注老年人衰弱

> 更新时间：2026-09-16 (UTC+8)

人口老龄化已成为一种全球现象，中国是老年人口最多的国家。国家统计局数据显示，2023年末，中国60周岁及以上人口超2.96亿，占总人口的21.1%。老年人健康问题是老龄化社会中最突出的问题。衰弱是一种与增龄相关的老年综合征，常见于高龄和多疾病共存的老年人。老年人衰弱表现为对突发情况的应对能力降低，发生跌倒、功能下降、行动不便、失能和死亡的风险增加。早期衰弱是一个可逆的过程，因此在老年人群中对衰弱进行预防非常重要。

一、衰弱的定义衰弱是导致老年人机能下降和死亡的主要因素。我们将衰弱定义为老年人以肌少症为基本特征的，全身多系统构成的稳定体系受损，导致生理储备下降、抗打击能力减退及应激后恢复能力下降的状态，是最具临床意义的老年综合征。临床上可分为健康、衰弱前期、衰弱老年人。二、衰弱的危险因素衰弱是一种复杂的多因素综合征，包括遗传、增龄、性别、疾病、药物、营养不良等。常见的危险因素可分为不可控的危险因素和可控的危险因素。1、不可控的危险因素：包括遗传、增龄和性别。其中年龄被认为是衰弱的独立危险因素之一，随增龄衰弱的患病率成倍上升。女性是衰弱的易感人群，主要原因可能是绝经后妇女雌激素迅速丢失，对肌肉力量、神经肌肉功能和姿势稳定性产生了负面影响。2、可控制的危险因素：包括社会经济状况、生活方式、疾病、老年综合征、营养、药物、心理和全生命周期健康管理等因素。其中未婚、独居、社会孤立和经济状况差的人群衰弱患病率较高；吸烟、酗酒、缺乏运动、个人卫生情况差等不良生活方式会增加衰弱的发生风险；许多慢性病如高血压、冠心病、脑卒中、糖尿病、慢性疼痛、骨质疏松、痴呆等均可促进衰弱的发生；老年人营养状况与衰弱相互影响相互促进，易形成恶性循环；老年人不合理的多重用药情况可增加衰弱的发生；焦虑、抑郁、睡眠障碍等是老年人常见的心理疾病，一定程度上也可增加衰弱的发生率；个体从妊娠期、新生儿期直至青春期、中年期、老年期与临终期整个过程称之为全生命周期，健全的生命周期健康管理，有利于减少衰弱的发生。

三、如何预防衰弱1、保持健康的生活方式：包括规律的生活起居、良好的卫生习惯、戒烟限酒、充足的睡眠、保持心理健康等。2、保证合理、充足的营养：营养干预是预防老年人衰弱的重要手段之一，建议老年人饮食上保证充足的能量供给，并补充充足的蛋白质，必要时可联合补充营养制剂。患有慢性疾病的老年人，应针对不同疾病，选择个性化的营养干预方案。如高血压病人饮食中应注意盐分的摄入，糖尿病病人应注意碳水化合物及蛋白质的摄入。

3、运动锻炼：运动锻炼被认为是目前预防和治疗衰弱的首选方案，可以改善躯体功能、提高生活自理能力、生活质量、心理健康以及对受伤和跌倒等事件的抵抗力。推荐老年人依照自身情况，个性化的选择如有氧运动、伸展或柔韧性运动、抗阻训练、力量及平衡训练，逐渐增加至适合自己的运动强度，并长期坚持锻炼。同时建议在家人陪伴下进行，以保证运动安全性。

4、积极学习老年人健康知识，定期到综合医院或老年专科医院进行老年综合评估，帮助指导制定计划，提高生活质量。（文中图片来源于网络）
