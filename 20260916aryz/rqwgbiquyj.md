# 做二代试管婴儿的夫妻在进周前要做哪些检查项目？

> 更新时间：2026-09-16 (UTC+8)

在进行二代试管婴儿（ICSI，单精子注射）之前，夫妻双方需要进行全面的检查，以确保身体状况适合接受治疗，并提高成功率。以下是一些常见的检查项目和注意事项：

## 1. 女方检查项目
1.1 生殖系统检查

妇科检查：通过常规妇科检查评估生殖器官的健康状况，包括子宫、卵巢等。

阴道超声波检查：用于观察子宫内膜厚度、卵巢大小及卵泡发育情况。

输卵管通畅性检查：如宫腔镜或输卵管造影，确认输卵管是否通畅。
1.2 内分泌功能检查
激素水平测定：包括促卵泡生成素（FSH）、黄体生成素（LH）、雌二醇（E2）、孕酮（P）、睾酮（T）等，了解卵巢功能及内分泌状态。

甲状腺功能检测：检查甲状腺功能是否正常，因为甲状腺问题可能影响怀孕。
1.3 免疫学检查
抗精子抗体检测：排除免疫因素导致的不孕不育。

自身免疫性疾病筛查：如抗磷脂抗体综合征等，这些疾病可能影响胚胎着床。
1.4 感染性疾病筛查
肝炎、梅毒、艾滋病等：确保女方无传染性疾病，避免对胎儿造成危害。
1.5 遗传学检查
染色体核型分析：排查遗传性疾病风险，特别是有家族遗传病史的情况下。

地中海贫血筛查：对于高发地区人群尤为重要。

## 2. 男方检查项目
2.1 精液分析
精液常规检查：评估精子数量、活力、形态等指标。

精子DNA碎片率检测：判断精子质量，过高的DNA碎片率会影响受精成功率。
2.2 生殖系统检查
睾丸超声波检查：了解睾丸结构及功能，排查隐睾等问题。

前列腺液检查：评估前列腺健康状况，排除前列腺炎等疾病。
2.3 内分泌功能检查
男性激素水平测定：如睾酮、促卵泡生成素（FSH）、黄体生成素（LH）等，评估睾丸生精功能。
2.4 感染性疾病筛查
肝炎、梅毒、艾滋病等：确保男方无传染性疾病，保护女方及未来宝宝的健康。
2.5 遗传学检查
染色体核型分析：排查遗传性疾病风险，特别是有家族遗传病史的情况下。

## 3. 双方共同检查项目
3.1 血常规检查
血红蛋白、白细胞计数等：评估整体健康状况，确保没有贫血或其他血液问题。
3.2 凝血功能检查
凝血酶原时间（PT）、活化部分凝血活酶时间（APTT）等：确保凝血功能正常，预防手术过程中可能出现的出血风险。
3.3 心电图检查
心电图：评估心脏功能，确保患者能够承受后续的治疗过程。
3.4 肝肾功能检查
谷丙转氨酶（ALT）、谷草转氨酶（AST）、肌酐、尿素氮等：评估肝肾功能，确保药物代谢及排泄正常。
3.5 传染病筛查
乙肝、丙肝、梅毒、艾滋病等：确保双方无传染性疾病，保障家庭成员的健康。

## 4. 心理准备与咨询

除了生理上的准备，心理准备同样重要。夫妻双方可以参加医院提供的心理咨询课程，了解整个治疗过程，减轻焦虑情绪，增强信心。

## 5. 生活方式调整

在进入周期前，建议夫妻双方保持良好的生活习惯：

戒烟戒酒：减少有害物质对生殖系统的影响。

均衡饮食：摄入足够的营养，特别是叶酸、维生素D等对孕育有益的营养素。

适量运动：保持适度的体育锻炼，增强体质。

规律作息：保证充足的睡眠，避免熬夜。

## 6. 医疗团队沟通

在整个准备过程中，定期与医生沟通，根据个人情况调整治疗方案。医生会根据检查结果制定个性化的治疗计划，确保每个环节都顺利进行。

通过上述全面的检查和准备，夫妻双方可以在进入二代试管婴儿周期时，最大限度地提高成功率，迎接健康的宝宝到来。
